# Release Checklist

1. Read [the rehearsal procedure](references/rehearsal.md) and current product requirements.
2. Run the production verification gate and UI review; collect evidence against the release commit.
3. Rehearse offline scanning/reconnection on actual gate devices, concurrent ordering, and backup restore in an isolated environment.
4. Record devices, network conditions, load, errors, timings, and recovery outcomes. Missing product flows are blockers, not passes.
5. Present a go/no-go report and remaining owner actions. This skill does not authorize production deletion, spending, or deployment.
