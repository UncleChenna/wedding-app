# Bundled typefaces

Sources and SHA-256 hashes are pinned in provenance.json. Original SIL OFL licenses are included beside each family. Complete assets retain the full upstream glyph sets. Common Next primary subsets cover the original Latin ranges U+0000-00FF, U+2000-206F and U+20A0-20CF plus the supported Igbo characters documented below. Complementary unicode-range declarations keep complete files off the initial Latin download path while preserving other characters.

The retained original Latin subsets were generated with fonttools4.60.1 pyftsubset from the same prepared TTF sources, using --unicodes=U+0000-00FF,U+2000-206F,U+20A0-20CF, --layout-features=<family-specific list from provenance.json>, --name-IDs=_, --name-legacy, --name-languages=_, --notdef-glyph, --notdef-outline, --recommended-glyphs and --glyph-names, then the same pinned WOFF2 compressor. The complete files are not removed. Browser tests prove on-demand non-Latin loading and identical rasterized sample glyphs at weights400/500/600; unit tests compare the requested character coverage.

The primary OpenType feature lists were inspected from the retained Google-font production build at base fd91e877e29b32ef911acfd45036ad65767732c7. They preserve its feature availability rather than introducing unused alternate glyph sets into first paint. Complete-font assets retain additional features and glyphs.

TICKET-116's `*-common.woff2` Next primary faces are generated by `scripts/generate-common-fonts.py` with `fonttools[woff]==4.60.1`. `common-manifest.json` records source/output hashes, sizes, supported Igbo characters and the same family-specific layout features approved in `provenance.json`. Each common face combines the existing Latin face's character coverage and supported canonical decomposition marks with supported precomposed Ń/ń, Ṅ/ṅ, Ị/ị, Ọ/ọ and Ụ/ụ. Keeping these in one face preserves mixed-word shaping, including Cormorant italic. The original Latin assets remain sources for the separately generated native ordering/offline fonts.

The complete originals remain available for other Unicode, including combining tone marks. This does not add glyphs absent from the original: Jost lacks precomposed cmap entries for Ṅ/ṅ, Ị/ị, Ọ/ọ and Ụ/ụ, and Playfair lacks precomposed Ṅ/ṅ. Supported canonical decomposition marks remain in common faces so browser shaping retains original coverage; characters the original cannot shape retain the existing metric fallback. Complete CSS ranges exclude the documented common characters so a font swap cannot trigger an unnecessary complete-font request. Browser checks compare actual common/fallback rendering to the original at all three approved weights and verify that unsupported/common requests follow the intended paths.
