# Ordering font subsets

Generated by `scripts/generate-order-fonts.py` using `fonttools[woff]==4.60.1` from
the existing approved Latin WOFF2 faces, with a separate small Igbo subset from
the complete originals. Original family licenses remain in
`src/modules/theming/fonts/*-OFL.txt`; the fonts retain their license metadata.

These fonts cover common UI/menu characters only. Complementary CSS ranges load
the original complete face for every other supported character. Do not use these
files without that fallback. The UI uses weights 400–600; subsets retain the original variable axes and glyph shapes.

Regenerate in a disposable Python environment when the source faces change.
The manifest records source/output hashes, and browser tests compare actual
rendered pixels at 400, 500 and 600, including accented fallback text.
