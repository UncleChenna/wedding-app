# Plan: Harden base components for focus, tap targets and dialogs

- Task: TICKET-017
- Module(s): shared (base UI)
- Date: 2026-10-22

## Goal

Make Button, Card, Input, Sheet and Toast meet the 44px, focus, dialog and non-colour rules before features reuse them.

## Acceptance criteria

- [x] Each component has tests for keyboard operation and labels.
- [x] Sheet traps focus, closes on Escape and restores focus to its trigger (e2e).
- [x] axe reports no violations on /dev/theme in both themes.

## Approach

1. Button: 44px minimum for every size; reduced-motion spinner.
2. Toast: tone icon and screen-reader label; assertive region for errors; 44px dismiss with focus ring.
3. Sheet: explicit Tab trap (native dialog does not wrap Tab).
4. `e2e/a11y.spec.ts` at 375px: sheet keyboard flow, 44px sweep, axe closed/open.
5. Add `@axe-core/playwright` (owner-approved lockfile write).

## Tests first

Unit tests for sizes, focus, labels, spinner, toast regions and icons, Card heading and Input; e2e for sheet, targets and axe. All failed before the changes.

## Risks and open questions

- `sm` buttons are taller (36→44px); dense admin layouts may need spacing review later.
- All-routes axe coverage remains TICKET-128.
