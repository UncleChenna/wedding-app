# TICKET-031 staff PIN sign-in

Base: develop `df8a970bc88b2c7b6664f26190a6c49abd8d3e1e`. Owner: divine.

Implement six-digit scrypt credentials, signed httpOnly sessions bound to a device,
and separate gate/kitchen/bar entry. Return friendly wrong, expired and locked
states without returning credentials. Recheck current role, revocation and expiry
on access. Administrative account creation remains TICKET-096.

Start with behavioural tests for credential encoding, verification and invalid
inputs. Add persistent device attempt accounting with atomic concurrency control;
an in-memory counter is insufficient across application instances. Prepare the
schema and exact generated migration proposal for authorization before committing
protected output. Session expiry must respect ADR 0020's event cutoff.

Verify role isolation, five failures per ten-minute window, expiry, tampering,
revocation and concurrent attempts. Exercise real database constraints and the
PIN journey on mobile and desktop. Run quick and full gates and all-theme UI
checks. Record any physical-device checks separately without claiming completion.

Risks: expensive PIN verification, guessing across fresh devices, deployment
signing-key configuration, and venue time zone still TBD. No production migration
or invented event cutoff is authorized by this implementation.
