# TICKET-102: Service-worker approach

Compare the installed Next 16.4.2 PWA guidance and Serwist's Turbopack integration. Prototype a narrow custom worker with synthetic public files, precaching, runtime fallback and explicit private-route exclusion. Build with Cache Components and Turbopack unchanged; measure worker bytes and build/static-output impact. Keep the prototype outside product routes and remove temporary public files automatically. Record alternatives, update/data safety, scope boundaries and downstream acceptance tests in an ADR. Verify the repository fully; human review and merge remain separate.
