# TICKET-141: Request-scoped action logging

Add a server-only action wrapper that validates an incoming x-request-id or generates a UUID, binds an independent child logger, and emits structured lifecycle messages without inputs/results/error text. Preserve handler return and thrown-error semantics. Pin request IDs across child/field bindings and prevent depth-limited serialization from leaking unredacted nested objects. There are currently no feature Server Actions to migrate; document future adoption. Test header validation, generated IDs, concurrent requests, every lifecycle line, redaction and error propagation before quick/full verification.
