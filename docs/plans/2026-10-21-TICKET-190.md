# TICKET-190: Live local dashboard

Serve the existing board on loopback only. Refresh through a bounded asynchronous CLI child process (20-second remote polling plus debounced file watching), keeping HTTP responsive and tracked files untouched. Serve same-origin GET endpoints only. Retain last valid data on errors and expose connection/last-success state. Poll from the browser without page reload; preserve filters, theme, details and keyboard focus. Keep snapshot export and add an optional folder-open VS Code task. Tests cover request restrictions, watching, polling, cleanup, outage/recovery, client state and responsive screenshots. No public service or mutation endpoints.
