# Ticket handoffs

Each ticket owns `docs/handoffs/TICKET-NNN.md`. Read its file before continuing work; update only that ticket’s handoff. Do not maintain a shared newest-first index.

Record date, owner/agent/branch, resulting changes, checks with evidence, lessons, exact next actions/blockers, base commit and PR link. Preserve earlier material evidence when updating a handoff. Historical entries remain in [progress.md](../progress.md).

The visual board (`pnpm t:dashboard`) and CLI (`pnpm t:board`, `pnpm t:next`) provide cross-ticket state from the ledger. These handoffs do not replace ticket statuses.
