# Offline fallback fonts

Generated by `scripts/generate-offline-fonts.py` using `fonttools[woff]==4.60.1`.
Sources are the existing licensed Latin fonts in `src/modules/theming/fonts/`;
the original licenses remain there. Font copyright/license name records are
retained. Install the pinned generator in a disposable Python virtual environment,
then run its Python interpreter against the script from the repository.

These fonts cover only `src/modules/shared/lib/offline-copy.json`, including
uppercase labels, with weights400–600 for all permitted theme role assignments.
Do not reuse them for guest names or arbitrary text. The generated manifest
records source and output SHA256 hashes, byte counts and metric fallback CSS.
Changing copy or source fonts requires regeneration and the focused manifest
tests plus actual cold-offline font rendering checks.
