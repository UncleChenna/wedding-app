# Roadmap

Run `pnpm t:render` to generate `artifacts/tickets/ROADMAP.md`, including epic progress,
milestones and dependency chains. Run `pnpm t:dashboard` for visual epic progress.
Use `pnpm t:next` for live readiness and `pnpm t:show <id>` for blockers.

This stable entry point is not regenerated by ticket commands.
