# TICKET-104: Generate maskable icons, Apple touch icons and splash screens

## Context

Android needs maskable icons; iOS needs apple-touch-icon and startup images.

See: [Design principles](../docs/prd.md#design-principles).

## Scope

- Monogram-based icons in 192/512 (any + maskable), 180 Apple touch, iOS splash images for common sizes.
- Generated by a script, not hand-exported.

## Out of scope

- App store assets.

## Acceptance criteria

- [x] Maskable icon passes maskable.app safe-zone check (screenshot).
- [x] Browser checks confirm the generated Apple touch icon is advertised and publicly served; actual iOS home-screen rendering is retained as an unchecked release requirement in TICKET-201 and the real-device installation suite in TICKET-114.
- [x] Generation script is reproducible (unit).

## Test plan

- Unit: Icon script output sizes.
- Manual: Install on iOS and Android.
- Gate: `pnpm verify` passes; UI tickets also record the UI checklist (docs/ui-checklist.md).

## Files likely touched

- `scripts/`
- `public/icons/`
- `src/app/layout.tsx`
